# 应该没人看

将像素图转换为拼豆（Perler Beads）图纸的纯前端小工具。

## 功能

- 读取图片原始 RGBA，透明像素直接映射为空位（不放置拼豆），不做白底填充
- 按厂家色板做 RGB 最近色拟合，31 个厂家可切换（数据见 `get-colors.json`）
- 画板视图：行列数字（每 4 个加粗）、网格线（每 4 格加粗）、可选格子内显示色号
- 内容包围盒统计（空白不计）+ 实物尺寸模拟（大号 5mm/格、小号 2.6mm/格）
- 编辑功能：画笔 / 橡皮 / 油漆桶 / 撤销 / 重做（保存结果为编辑后内容）
- 导出：PNG 图纸（含材料清单与参数）、CSV 清单、JSON 图纸数据
- 设置本地持久化（localStorage）
- 桌面与移动端适配

## 数据来源

色板数据来自 [abearxiong/get-colors-from-beans](https://git.xiongxiao.me/abearxiong/get-colors-from-beans)，感谢作者分享。

## 声明

本工具仅支持简单拟合处理，无法使用 AIGC 功能及其他风格化处理。编辑功能仅供微小颜色或细节调整。如有高级编辑需要，请寻找其他工具或像素画编辑器。
